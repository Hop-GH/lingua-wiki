# Lingua

[English](README.md) | [Dansk](README.da.md)

## Description

Lingua is a hub for tools, resources, and more within the field of linguistics. It is an open-source project made by and for students, currently maintained by linguistics students at the University of Copenhagen (Class of 2029).

The website is bilingual (EN/DA).

## Overview

### IPA/DIPA Charts with Audio

Interactive audio charts for IPA as described in R. Schachtenhaufen’s *Ny Dansk Fonetik* (*New Danish Phonetics*) and Danish IPA (DIPA) from *Udtalt* by J.H. Petersen et al.

Simply click a symbol to hear the sound it represents.

*All credit goes to Awiso for creating these awesome charts and recording the audio files.*
