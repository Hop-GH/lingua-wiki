# lingua-wiki

# Foreword
Website for sharing and creating useful tools and resources for linguistics. It is is an open-source project made by and for students, currently maintained by linguistics students at the University of Copenhagen, Class of 2029. The website is billingual (EN/DA).

# Tools & Resources


**IPA/DIPA Charts with Audio**

Interactive audio charts for IPA as described in R. Schachtenhaufen’s *Ny Dansk Fonetik* (New Danish Phonetics) and Danish IPA (DIPA) from *Udtalt* by J.H. Petersen et al. Simply click a symbol to hear the sound it represents.

Credit goes to Awiso for making these awesome charts and recording the audio files.
